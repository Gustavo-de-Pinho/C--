# **GLOSSÁRIO:**
* std::cout & std::cin : *STD contém os recursos da biblioteca padrão de C++, o cout você indica um output para o usuário, o cin o input do usário*
* Tipos: *Eles permitem armazenar diferentes tipos de informações com tamanhos e precisões variados.*
  
|  TIPO  | ARMAZENAMENTO |            P/ Q SERVE            |
|:------:|:-------------:|:--------------------------------:|
| bool   | 1 byte        | true or false                    |
| char   | 1 byte        | 1 caracter ASCII                 |
| int    | 4 bytes       | N° inteiro                       |
| float  | 4 bytes       | N° decimal de baixa precisão /32 |
| double | 8 bytes       | N° decimal de alta precisão /64  |
| void   | 0 bytes       | Representa o vazio               |
